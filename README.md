# CampusFlow

Веб-приложение для бронирования аудиторий кампуса: поиск свободных пространств по дате, времени, вместимости и оборудованию, оформление бронирований и управление аудиториями.

**Демо:** https://campusflow-peiv.onrender.com/  
Доступ к демо может требовать VPN из-за домена `onrender.com`. Приложение также можно запустить локально.

## О проекте

CampusFlow помогает студентам, преподавателям и сотрудникам кампуса быстро находить подходящие аудитории и бронировать их без пересечений. Пользователь задаёт параметры поиска, а система показывает пространства со свободными интервалами на выбранную дату.

## Возможности

- 🔍 **Поиск аудиторий** — фильтрация по корпусу, вместимости и оборудованию.
- 🕒 **Свободные интервалы** — просмотр доступного времени с шагом 30 минут в пределах рабочего дня 09:00–18:00.
- 📅 **Бронирование аудиторий** — выбор свободного интервала и создание брони.
- 🙋 **Мои бронирования** — просмотр и отмена собственных активных бронирований.
- 🛠 **Панель администратора** — просмотр всех бронирований и их отмена.
- 🏫 **Управление аудиториями** — добавление, редактирование и удаление аудиторий (только администратор).
- 📊 **Статусы аудиторий** — отображение свободных и занятых аудиторий и активных броней на выбранную дату.
- 📥 **Экспорт в CSV** — выгрузка списка бронирований из панели администратора.
- Каталог включает 12 аудиторий с описанием вместимости и оборудования.

## Технологии

- **Frontend:** HTML5, CSS3, JavaScript.
- **Backend:** Python + Flask.
- **Хранение данных:** JSON-файл `data.json`.
- **API:** REST API, формат обмена данными — JSON.
- **Деплой:** Render.
- **Система контроля версий:** Git и GitHub.

## Локальный запуск

Требуется Python 3.10 или новее.

1. Клонируйте репозиторий:

   ```bash
   git clone https://github.com/nazgulsultanova07/CampusFlow.git
   cd CampusFlow
   ```

2. (Рекомендуется) создайте виртуальное окружение:

   **Windows:**
   ```bash
   python -m venv .venv
   .venv\Scripts\activate
   ```

   **macOS / Linux:**
   ```bash
   python3 -m venv .venv
   source .venv/bin/activate
   ```

3. Установите зависимости:

   ```bash
   pip install -r requirements.txt
   ```

4. Запустите приложение:

   ```bash
   python app.py
   ```

5. Откройте в браузере адрес, указанный Flask в терминале. По умолчанию это:

   http://127.0.0.1:5000

В MVP используется демонстрационная авторизация. Эти учётные данные предназначены только для демонстрации проекта; перед production-использованием необходимо внедрить полноценную аутентификацию и безопасное хранение паролей.

## Правила бронирования

- Рабочее время: 09:00–18:00.
- Время начала и окончания брони должно быть кратно 30 минутам.
- Дата бронирования не может быть в прошлом.
- Время окончания должно быть позже времени начала.
- Учитываются только активные бронирования.
- Пересечение интервалов для одной аудитории и даты запрещено; соприкосновение границ интервалов конфликтом не считается.
- Пользователь может отменять только собственные бронирования; администратор может отменять любые бронирования.
- Удаление аудитории с активными бронированиями запрещено.

## Основные API-маршруты

### Авторизация и аудитории

- `POST /api/auth/login` — вход в систему.
- `GET /api/rooms` — список аудиторий с фильтрами.
- `GET /api/rooms/{id}` — информация об аудитории.
- `GET /api/rooms/{id}/free-slots?date=YYYY-MM-DD` — свободные интервалы аудитории на дату.

### Бронирования

- `POST /api/bookings` — создать бронирование (требуется авторизация).
- `GET /api/bookings/my` — список бронирований текущего пользователя.
- `DELETE /api/bookings/{id}` — отменить собственное бронирование.

### Администрирование

- `GET /api/admin/bookings` — список всех бронирований (только администратор).
- `DELETE /api/admin/bookings/{id}` — отменить любое бронирование (только администратор).
- `POST /api/admin/rooms` — добавить аудиторию (только администратор).
- `PUT /api/admin/rooms/{id}` — изменить аудиторию (только администратор).
- `DELETE /api/admin/rooms/{id}` — удалить аудиторию (только администратор; при наличии активных броней удаление отклоняется).
