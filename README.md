# CampusFlow

Веб-приложение для поиска и бронирования аудиторий кампуса.

## Возможности

- Поиск аудиторий по корпусу, вместимости и оборудованию.
- Отображение свободных интервалов и бронирование с шагом 30 минут.
- Личный список бронирований и отмена своих активных броней.
- Админ-панель: просмотр всех броней, отмена брони, экспорт в CSV.
- Управление аудиториями: добавление, редактирование и удаление (только администратор).
- Статус каждой аудитории на выбранную дату: свободна, частично занята или забронирована полностью.

## Технологии

- Frontend: HTML, CSS, JavaScript.
- Backend: Python, Flask.
- Хранение: `data.json`.
- API: REST/JSON.

## Локальный запуск

Требуется Python 3.10+.

```bash
python -m venv .venv
# Windows:
.venv\Scripts\activate
# macOS/Linux:
source .venv/bin/activate

pip install -r requirements.txt
python app.py
```

Откройте http://127.0.0.1:5000.

## Демо-аккаунты

| Роль | Логин | Пароль |
|---|---|---|
| Студент | student1 | student1 |
| Студент | student2 | student2 |
| Администратор | admin | admin |

В этом MVP используются демонстрационные токены. Для production необходимо заменить mock-auth на безопасную систему аутентификации и хранить пароли в виде хешей.

## Правила бронирования

- Рабочее время: 09:00–18:00.
- Шаг начала и окончания брони: 30 минут.
- Дата не может быть в прошлом.
- Конфликт проверяется по пересечению интервалов; касание границ не является конфликтом.
- Учитываются только активные бронирования.
- Удаление аудитории запрещено, пока у неё есть активные бронирования.

## API управления аудиториями

- `POST /api/admin/rooms` — создать аудиторию.
- `PUT /api/admin/rooms/{id}` — изменить аудиторию.
- `DELETE /api/admin/rooms/{id}` — удалить аудиторию. Ответ `409 ROOM_HAS_ACTIVE_BOOKINGS`, если у аудитории есть активные бронирования.
- Все три endpoint требуют Bearer-токен пользователя с ролью `admin`.

## Экспорт CSV

В админ-панели нажмите «Экспорт бронирований в CSV». Файл содержит идентификатор, аудиторию, пользователя, дату, время, статус и комментарий. Экспорт доступен только после входа администратором.
